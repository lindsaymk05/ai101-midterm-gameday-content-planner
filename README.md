# GameDay Content Planner

## Project Name and Audience
GameDay Content Planner is a website designed for college athletics social media staff, interns, and student workers who create content for sports teams.

## Purpose
Managing social media during game days can be stressful because there are many different posts to prepare and publish. This website will help users organize their content, plan when posts should go out, and keep track of completed tasks.

## First Two Features

1. **GameDay Content Checklist:** Users can select a sport and organize content such as graphics, starting lineups, score updates, and final score posts. They can check off tasks as they complete them.
2. **Posting Schedule:** Users can organize pregame, in-game, and postgame content so they can keep track of what needs to be posted and when.

A possible future feature is AI-assisted caption suggestions to help users create social media captions more quickly.

## How to Run It
The first version will be a website built with HTML, CSS, and JavaScript. Users will open the website in a browser. Instructions will be updated as the project develops.
